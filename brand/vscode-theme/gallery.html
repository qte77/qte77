EyeRest VS Code Theme Gallery

Every EyeRest color variant, side by side — swatches plus a live VS Code chrome mockup for light and dark, so you can compare hue and contrast without installing seven themes.

All seven are zero-blue and pass WCAG AA on text/muted/link in both schemes. The mockups show exactly what the generated brand/vscode-theme/ ships today — workbench chrome only. No tokenColors are defined yet, so code text renders flat in one color; only line numbers, the active-line highlight, the cursor, and the status-bar git dot are themed.

See README.md for install instructions, or DESIGN.md for the token source of truth.

Source of truth: brand/DESIGN.md → generated into brand/ui-kit/eyerest.css and brand/vscode-theme/ by make -C brand ui_kit vscode_theme. Terracotta and Plum were derived with Adobe Color's Analogous and Triad harmony rules around the brand's zero-blue exclusion band — see DESIGN.md "Palette derivation".
