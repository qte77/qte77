# Hackathons

Recent SF hackathon builds — proof of execution, not required reading. Each is a
standalone repo; none depend on the estate's orchestrators.

- [`2026-08-26-AgentNativeHack-FT-CF-SF`](https://github.com/qte77/2026-08-26-AgentNativeHack-FT-CF-SF)
  (2026-08-26) — an idle-discovery agent that self-selects a goal from live signals
  and executes real cross-repo writes over MCP, checkpointed for deterministic
  replay. Built for the Agent Natives Builders Hackathon.
- [`2026-08-15-SF-0HumanCompanyHack-firm`](https://github.com/qte77/2026-08-15-SF-0HumanCompanyHack-firm)
  (2026-08-15) — "Broker," an agent-run firm with no human employees, trading
  across a real trust boundary with a separately-maintained
  [Client](https://github.com/qte77/2026-08-15-SF-0HumanCompanyHack-client)
  counterparty. Built for the Zero-Human Company Hackathon by Terac.
- [`2026-08-14-SF-AWS_EnterpriseHack`](https://github.com/qte77/2026-08-14-SF-AWS_EnterpriseHack)
  (2026-08-14) — "Ledgerline," a human-in-the-loop governance layer that gates
  every cross-system write behind explicit authorization. Built for the SF
  Enterprise Hackathon.
- [`ldnmxx-hack`](https://github.com/qte77/ldnmxx-hack) — a config-driven agent
  that streams its own UI on a single Cloudflare Worker.
